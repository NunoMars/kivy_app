# Test rapide avec Kivy Launcher

## Installation
1. Installer "Kivy Launcher" depuis Google Play Store
2. Créer un dossier sur votre téléphone/émulateur: /sdcard/kivy/
3. Copier tous vos fichiers (.py, .kv, images) dans ce dossier
4. Lancer Kivy Launcher et sélectionner votre application

## Avantages
- Pas besoin de compilation
- Test rapide du code
- Idéal pour le développement

## Inconvénients  
- Nécessite Kivy Launcher installé
- Pas une vraie APK autonome
- Interface moins native
