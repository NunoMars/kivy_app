🔜 PROCHAINES ÉTAPES
═══════════════════════════════════════════════════════════════════════════

  [ ] 1. Build et tester mode TEST
  
  [ ] 2. Déployer config production (.\deploy_config.ps1 prod)
  
  [ ] 3. Attendre 1h (délai AdMob)
  
  [ ] 4. Vérifier bannière s'affiche
  
  [ ] 5. Créer bloc Interstitiel sur AdMob :
         https://apps.admob.com/
         → Ad units → Add ad unit → Interstitial
  
  [ ] 6. Mettre à jour config.production.json :
         "admob_inter_id": "ca-app-pub-5749803259882370/XXXXXXXXXX"
         "interstitial_enabled": true
  
  [ ] 7. Redéployer et tester système hybride


🐛 DEBUGGING
═══════════════════════════════════════════════════════════════════════════

  Bannière ne s'affiche pas ?
  
    1. Vérifier config :
       adb shell run-as org.tarot.macartedetarot cat files/config.json
       → "banner_enabled": true
    
    2. Vérifier logs :
       adb logcat -s "AdMob:* ResponseScreen:*"
       → "Showing banner"
    
    3. Attendre 1 heure (nouveaux blocs AdMob)
    
    4. Tester avec IDs Google de test :
       .\deploy_config.ps1 test
