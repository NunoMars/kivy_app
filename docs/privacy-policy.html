🔒 Politique de Confidentialité

Dernière mise à jour : 10 octobre 2025

Cette politique de confidentialité décrit comment l'application "Ma Carte de Tarot" collecte, utilise et protège vos informations personnelles.

1. Informations Collectées

1.1 Données Collectées Automatiquement

L'application peut collecter automatiquement les informations suivantes :

  • Données d'utilisation : Informations sur la façon dont vous utilisez l'application (nombre de tirages, fréquence d'utilisation)
  • Données de l'appareil : Type d'appareil, système d'exploitation, version de l'application
  • Données publicitaires : Identifiant publicitaire Google (GAID) pour la diffusion de publicités personnalisées via AdMob

1.2 Données NON Collectées

Nous ne collectons PAS :

  • Informations personnelles identifiables (nom, email, adresse)
  • Données de localisation précises
  • Contacts ou données sensibles de votre appareil
  • Historique de vos tirages de cartes

2. Utilisation des Informations

Les informations collectées sont utilisées pour :

  • Améliorer l'application : Analyser l'utilisation pour améliorer l'expérience utilisateur
  • Afficher des publicités : Google AdMob utilise votre identifiant publicitaire pour diffuser des publicités pertinentes
  • Analyser les performances : Comprendre comment l'application est utilisée

3. Publicités (AdMob)

Cette application utilise Google AdMob pour afficher des publicités. AdMob peut utiliser des technologies telles que les cookies et les identifiants publicitaires pour collecter des informations sur votre appareil et votre utilisation de l'application.

3.1 Types de Publicités

  • Bannières : Affichées sur l'écran de réponse après chaque tirage
  • Interstitielles : Publicités plein écran affichées périodiquement (tous les 5 tirages par défaut)

3.2 Personnalisation des Publicités

Vous pouvez contrôler les publicités personnalisées via les paramètres de votre appareil :

  • Android : Paramètres → Google → Annonces → Désactiver la personnalisation des annonces
  • Plus d'informations : https://support.google.com/ads/answer/2662922

3.3 Politique de Confidentialité AdMob

Pour plus d'informations sur la façon dont Google collecte et utilise les données : https://policies.google.com/privacy

4. Permissions de l'Application

L'application demande les permissions suivantes :

  • INTERNET : Nécessaire pour charger les publicités AdMob
  • ACCESS_NETWORK_STATE : Vérifier la connectivité réseau
  • AD_ID : Accéder à l'identifiant publicitaire Google pour les publicités personnalisées

Important : L'application fonctionne SANS connexion internet pour le tirage de cartes. Internet est uniquement nécessaire pour afficher les publicités.

5. Partage des Données

Nous ne vendons, n'échangeons ni ne louons vos informations personnelles à des tiers.

Les seuls tiers avec lesquels nous partageons des données sont :

  • Google AdMob : Pour la diffusion de publicités (selon leur propre politique de confidentialité)
  • Google Play Services : Pour les fonctionnalités de l'application Android

6. Sécurité des Données

Nous mettons en œuvre des mesures de sécurité appropriées pour protéger vos informations contre tout accès non autorisé, modification, divulgation ou destruction.

7. Données des Enfants

Cette application ne collecte pas sciemment d'informations personnelles d'enfants de moins de 13 ans. Si vous êtes parent et découvrez que votre enfant nous a fourni des informations personnelles, veuillez nous contacter pour que nous puissions les supprimer.

8. Vos Droits

Vous avez le droit de :

  • Accéder aux données que nous détenons sur vous
  • Demander la suppression de vos données
  • Vous opposer au traitement de vos données
  • Désactiver les publicités personnalisées dans les paramètres de votre appareil
  • Désinstaller l'application à tout moment

9. Modifications de cette Politique

Nous pouvons mettre à jour cette politique de confidentialité de temps en temps. Nous vous informerons de tout changement en publiant la nouvelle politique sur cette page et en mettant à jour la date de "Dernière mise à jour".

10. Conservation des Données

Les données d'utilisation anonymes sont conservées aussi longtemps que nécessaire pour améliorer l'application. Vous pouvez supprimer toutes les données en désinstallant l'application.

11. Transferts Internationaux

Les données peuvent être transférées et traitées dans des pays autres que votre pays de résidence, notamment aux États-Unis où sont situés les serveurs de Google AdMob.
