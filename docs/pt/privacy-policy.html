🔒 Política de Privacidade

Última atualização: 10 de outubro de 2025

Esta política explica como a aplicação "Ma Carte de Tarot" coleta, usa e protege seus dados.

1. Informações coletadas

1.1 Dados coletados automaticamente

A aplicação pode coletar automaticamente as seguintes informações:

  • Dados de uso: Número de sorteios, sessões e uso geral das funcionalidades.
  • Dados do dispositivo: Modelo, versão do sistema operacional e versão da aplicação.
  • Dados de publicidade: Identificador de publicidade Google (GAID) para exibir anúncios personalizados via AdMob.

1.2 Dados que NÃO coletamos

Não coletamos:

  • Informações pessoais identificáveis (nome, email, endereço)
  • Localização precisa ou coordenadas de GPS
  • Contactos, fotos ou dados sensíveis do dispositivo
  • Histórico das suas perguntas ou tiragens de tarot

2. Uso das informações

Os dados coletados são usados exclusivamente para:

  • Melhorar a aplicação: Analisar uso anônimo para otimizar a experiência.
  • Exibir anúncios: AdMob utiliza o GAID para anúncios relevantes.
  • Monitorar desempenho: Entender instalações, falhas e adoção de recursos.

3. Publicidade (Google AdMob)

A aplicação integra Google AdMob para exibir anúncios de banner e intersticiais. AdMob pode usar cookies ou identificadores únicos para fornecer e medir anúncios.

3.1 Tipos de anúncios

  • Banners: Aparecem na tela de resultado após cada tiragem.
  • Intersticiais: Tela cheia exibida periodicamente (padrão a cada 5 tiragens).

3.2 Controlo de personalização

Você pode controlar a personalização dos anúncios nas configurações do dispositivo:

  • Android: Configurações → Google → Anúncios → Desativar personalização.
  • Mais detalhes: https://support.google.com/ads/answer/2662922

3.3 Política do Google

Veja como o Google trata os dados: https://policies.google.com/privacy

4. Permissões da aplicação

Solicitamos as seguintes permissões Android:

  • INTERNET: Necessário para carregar anúncios AdMob.
  • ACCESS_NETWORK_STATE: Verifica a conectividade antes de carregar anúncios.
  • AD_ID: Acesso ao identificador de publicidade Google.

Importante: Os sorteios funcionam offline. Apenas os anúncios precisam de internet.

5. Compartilhamento de dados

Não vendemos nem alugamos dados pessoais. Eles são partilhados apenas com:

  • Google AdMob: Para exibição de anúncios conforme a política deles.
  • Google Play Services: Para funcionalidades essenciais do Android.

6. Segurança

Aplicamos medidas técnicas e organizacionais para proteger as informações contra acesso não autorizado.

7. Retenção

AdMob retém dados de acordo com as políticas do Google. Não guardamos dados pessoais nos nossos servidores.

8. Os seus direitos

Você pode:

  • Desativar anúncios personalizados nas configurações do dispositivo.
  • Desinstalar a aplicação para interromper qualquer coleta.

9. Alterações nesta política

Podemos atualizar esta política. Quaisquer mudanças serão publicadas aqui com a nova data.
