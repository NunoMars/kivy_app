💰 Monétisation AdMob

L'application intègre un système complet de publicités AdMob :

🎯 Bannière Publicitaire

  • Affichée sur l'écran de réponse (après tirage)
  • Position : Bas de l'écran
  • Non intrusive, revenus continus

📺 Interstitielle Plein Écran

  • Affichée tous les 5 tirages
  • Plein écran entre les actions
  • Fréquence configurable

⚙️ Configuration Flexible

Système de configuration JSON permettant de modifier les paramètres sans rebuild :

{ "ads_enabled": true, "ads_test_mode": false, "ads_frequency": 5, "banner_enabled": true, "interstitial_enabled": true }

🔧 Technologies Utilisées

  • Kivy 2.3.0 - Framework Python multiplateforme
  • KivMob - Intégration AdMob pour Kivy
  • Pillow - Traitement d'images
  • GitHub Actions - CI/CD automatisé
  • Buildozer - Build Android
  • Google Play Services - AdMob SDK 22.6.0
